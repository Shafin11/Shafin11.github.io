# Mohammad Omar Raihan — Portfolio

Personal portfolio website. Plain HTML, CSS and JavaScript with no build step and no external libraries (only Google Fonts).

## Open it on your computer
Double-click `index.html`, or for the best result run a small local server in this folder:

```
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Folder structure
```
index.html                 page content
assets/css/style.css       design, colours, dark/light themes
assets/js/main.js          all animations and interactions
assets/img/                profile photo
assets/docs/               CV (Download CV button)
```

## Editing tips
- Text: change it directly in `index.html`.
- CV: replace `assets/docs/Mohammad_Omar_Raihan_CV.pdf` with a new file of the same name.
- Photo: replace `assets/img/profile.jpg` and `assets/img/profile.webp` (square image).
- Skills bubbles: edit the `SKILLS` list in `assets/js/main.js`.
