## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Shafin11/Shafin11.github.io.git
```

### 2. Navigate to the Project

```bash
cd Shafin11.github.io
```

### 3. Start a Local Server

Using Python:

```bash
python -m http.server 8000
```

### 4. Open in Your Browser

Visit:

```text
http://localhost:8000
```

Alternatively, you can open `index.html` directly in your browser, although a local server is recommended.
